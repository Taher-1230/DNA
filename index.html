Step 2

Greedy Priority Queue Merging

Bottom-Up Tree Construction

Huffman's greedy strategy repeatedly selects the two nodes with the smallest frequencies and merges them into a new internal node whose frequency is the sum of both. Lower frequency bases end up deepest in the tree (longer codes), while high-frequency bases stay near the root (shorter codes).

To find the binary code for each base, start at the Root and follow the branches down to that leaf node. Every left branch appends a 0; every right branch appends a 1.

Algorithm Analysis & Viva Insights

Average Code Length ($L$): 1.50 bits/symbol

The expected number of bits used per nucleotide by Huffman coding.

Shannon Theoretical Entropy ($H$): 1.45 bits/symbol

The theoretical lower bound of compression according to Shannon's Source Coding Theorem.

Why 2 Bits per Base? Fixed Binary: $\lceil\log_2 4\rceil = 2$ bits

Since standard DNA has 4 bases, uncompressed binary uses 2 bits (e.g. A=00, C=01, G=10, T=11). When frequencies are biased, Huffman beats this baseline!
