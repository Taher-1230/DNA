Step 2

Min-Priority Queue & Greedy Merging

Greedy Choice Property

Greedy Strategy: At each step, take the two nodes with the smallest frequencies from the priority queue. Merge them into a new parent node with frequency equal to their sum, and insert the parent back into the queue. Characters with the lowest frequencies end up deepest in the tree (longer codes), while high-frequency characters remain closest to the root (shorter codes).

Step 3

Huffman Binary Tree (Prefix Code Tree)

Left = '0' Right = '1' Leaf Node (Character)

To find the binary code for each character, start at the Root and follow the path down to that leaf node. Every left branch appends a 0; every right branch appends a 1. Because characters only reside at leaf nodes, no code is a prefix of another (Prefix-Free Property).

Step 4

Huffman Code Table vs Fixed 2-Bit Binary

Variable-Length vs Fixed-Length

Standard fixed-length binary requires 2 bits for each character ($2^2 = 4$). Huffman assigns variable-length codes: high-frequency characters get shorter codes (e.g., 1 bit), saving bits overall.

DAA Concept Implementation & Viva Guide

Paradigm

Greedy Algorithm Approach

Huffman's algorithm makes the locally optimal choice at each step by merging the two lowest-frequency nodes, leading to a globally optimal prefix tree with minimal total weighted path length.

Properties

Greedy Choice & Optimal Substructure

Greedy Choice: The two lowest frequency symbols can always be placed as sibling leaves at the maximum depth of an optimal tree.
Optimal Substructure: Merging the two lowest symbols reduces the problem of size k to an optimal subproblem of size k-1.

Complexity

Time & Space Complexity

Time Complexity: O(N)
• Frequency Counting: O(N)
• Priority Queue Merges: O(K log K) = O(1) since K ≤ 4
• Encoding & Decoding: O(N)
Auxiliary Space: O(1)
• Huffman tree has at most 2K - 1 = 7 nodes.

Prefix Code

Prefix-Free Property

No codeword is a prefix of any other codeword because all characters are located at leaf nodes. This allows instant, unambiguous decoding without delimiters like spaces or commas.

Comparison

Fixed (2-Bit) vs Variable (Huffman)

With 4 symbols {A, T, G, C}, fixed binary needs ⌈log₂ 4⌉ = 2 bits each. When character frequencies are skewed (unequal), Huffman allocates fewer bits (1 bit) to frequent characters, achieving < 2.00 bits/character average.

Test Cases

Best Case vs Worst Case in DAA

Best Case: Heavily skewed frequencies (e.g., A=70%). Frequent characters get 1-bit codes, maximizing bit savings (up to 40%+).
Worst Case: Equal frequencies (25% each). Every character gets 2 bits, giving 0% savings.

Average Code Length (L): 1.50 bits/character

Expected number of bits per character: L = Σ (p_i × length_i).

Theoretical Minimum (Entropy H): 1.45 bits/character

Theoretical lower bound: H = -Σ p_i log₂(p_i). Huffman code length L is always within H ≤ L < H + 1.

Alphabet Size (K): K = 4 {A, T, G, C}

Because K is small and constant, tree operations take O(1) time and space.
